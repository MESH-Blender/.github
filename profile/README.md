## 🧠 Overview

**MESHmachine** is a specialized Blender add-on focused on precise hard-surface mesh editing and reconstructive modeling. It provides tools for refining existing geometry, reshaping edge treatments, correcting difficult intersections, and creating controlled transitions without depending entirely on subdivision-based techniques.

The add-on is particularly useful when a model has already gone through several modeling operations and its geometry needs further refinement. Instead of rebuilding an entire section, artists can modify bevels, chamfers, fillets, surface transitions, and other existing structures directly.

A major part of the workflow revolves around creating and adjusting transitional surfaces. Fuse and Unfuse operations, variable fillets, washouts, bevel editing, and chamfer reconstruction give users greater control over the way hard-surface forms connect to one another.

**MESHmachine** also extends beyond edge refinement with tools for boolean cleanup, custom normals, symmetry, mesh state management, and reusable surface details. This makes it suitable for mechanical assets, vehicles, industrial designs, sci-fi props, product visualization, architectural elements, and other detailed Blender projects.

## 🚀 Key Features

| Feature | Description |
|----------|-------------|
| 🔧 **Bevel Reconstruction** | Adjust and reshape existing bevel geometry instead of rebuilding edge treatments from the beginning. |
| 📐 **Chamfer Editing** | Modify chamfer widths and structures while maintaining greater control over surrounding mesh geometry. |
| 🌀 **Fuse Surfaces** | Generate smooth transitional surfaces between selected hard-surface regions for more refined forms. |
| ↩️ **Unfuse Workflow** | Reverse suitable fused transitions and regain access to the underlying mesh structures. |
| 🔄 **Unbevel & Unchamfer** | Restore selected treated edges toward sharper base geometry when earlier operations need to be reconsidered. |
| 📏 **Variable Fillets** | Create changing-radius transitions and washout-style surfaces for more sophisticated mechanical designs. |
| 🧩 **Boolean Cleanup** | Refine geometry created by boolean intersections and establish cleaner perimeter structures around cut areas. |
| 🗃️ **Stash System** | Preserve selected mesh states or objects as references that can be reused during later modeling operations. |
| 🧱 **Plug Detailing** | Insert reusable mesh components into surfaces to create mechanical and tertiary hard-surface details. |
| 📦 **Custom Plug Libraries** | Build and organize personal collections of mesh details for repeated use across different projects. |
| 🎯 **Normal Transfer** | Transfer custom normal information between mesh states to improve shading across complex hard-surface forms. |
| 📐 **Surface Flattening** | Straighten or flatten selected regions according to faces, edges, normals, or reference geometry. |
| 🪞 **Custom-Normal Symmetry** | Mirror mesh structures while retaining relevant custom normal information for consistent surface shading. |
| 🔁 **Mirror Conversion** | Turn mirrored structures into editable geometry when a permanent mesh result is required. |
| 🧠 **Advanced Selection Tools** | Quickly identify loops, sharp edges, vertex groups, and other important mesh components during modeling. |
| 🧱 **Wedge Creation** | Introduce controlled wedge-shaped geometry for additional hard-surface construction and detailing options. |

## Additional Information for Windows Users

**MESHmachine** is designed for hard-surface artists who need to keep refining geometry after bevels, chamfers, booleans, and other mesh operations have already been applied. Its reconstructive approach makes previously created forms easier to revisit and modify.

The Fuse, Unfuse, bevel, chamfer, and fillet tools are useful for developing mechanical housings, vehicles, industrial components, sci-fi assets, and detailed product models where controlled surface transitions are important.

The Stash and Plug systems extend the workflow beyond basic mesh editing, allowing artists to preserve useful geometry states and reuse detailed surface components across multiple projects.

**MESHmachine** combines edge refinement, topology correction, surface detailing, boolean cleanup, and custom-normal management inside Blender for a more controlled hard-surface modeling workflow.
